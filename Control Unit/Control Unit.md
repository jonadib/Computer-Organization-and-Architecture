## 1. What is a Control Unit?
 
The Control Unit (CU) is the part of the CPU that controls all other components.
 
It tells the CPU: **what to do, when to do it, and in what order.**
 
For example, for:
 
```
ADD R1, R2
```
 
the control unit generates signals that tell:
 
```
R1 → ALU
R2 → ALU
ALU → ADD
Result → R1
```
 
**Simple diagram**
 
```
                 Control Unit
                      │
             Control Signals
                      │
       ┌──────────────┼──────────────┐
       ↓              ↓              ↓
    Registers         ALU          Memory
```
 
---
 
## 2. What are Control Signals?
 
Control signals are binary signals generated by the control unit to control CPU operations.
 
They tell different parts of the CPU when to:
 
- Read a register
- Write a register
- Select an ALU operation
- Read memory
- Write memory
- Put data on the bus
For example:
 
- `R1out = 1` → means **put R1's contents onto the bus**.
- `R2in = 1` → means **load the value from the bus into R2**.
