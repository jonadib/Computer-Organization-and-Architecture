
Instead of using a large amount of physical logic, the control signals are stored as **microinstructions** in a special memory called **control memory**.

### Simple idea
 
Instead of physically wiring:
 
```
ADD  → these signals
SUB  → these signals
LOAD → these signals
```
 
we store the instructions for generating those signals in control memory.
 
---
 
## 5. What is a Microinstruction?
 
A microinstruction is a small control word that specifies the control signals needed for one or more micro-operations.
 
For example:
 
```
Y ← B
```
 
might require:
 
```
Bout = 1
Yin  = 1
```
 
The microinstruction contains these control bits.
 
---
 
## 6. Hardwired vs Microprogrammed
 
| Hardwired | Microprogrammed |
|---|---|
| Uses logic circuits | Uses microinstructions |
| Control signals generated by hardware | Control signals generated from control memory |
| Faster | Relatively slower |
| Difficult to modify | Easier to modify |
| Complex for large instruction sets | Easier for complex instruction sets |
| No control memory needed | Requires control memory |
| Commonly associated with RISC-style designs | Commonly associated with CISC-style designs |
 
### ⭐ Memorize
 
- **Hardwired** = Fast + Difficult to change
- **Microprogrammed** = Flexible + Easier to change
