# What is an Interrupt?

Interrupt — Easy Words

An interrupt is a signal that tells the CPU:

“Stop your current work for a moment and handle this important task.”

The CPU temporarily stops the current program and runs a special program called an Interrupt Service Routine (ISR).

After finishing the interrupt task, the CPU returns to the previous program and continues from where it stopped.

Simple Example

Suppose you are using a computer and suddenly press a key on the keyboard.

 - Normal Program

        ↓
 - CPU is working

        ↓
 - Keyboard sends Interrupt

        ↓
 - CPU pauses current work

        ↓
 - Runs ISR

        ↓
 - Handles the keyboard input

        ↓
 - Returns to Normal Program

        ↓
 - Continues execution


An interrupt is a signal that temporarily stops the current execution of the CPU and forces it to execute a special routine called an **Interrupt Service Routine (ISR)**. After servicing the interrupt, the CPU returns to the original program.

## Classification of Interrupts

### 1. Hardware Interrupts
* **Definition:** Interrupts generated by external hardware devices.
* **Examples:** Keyboard, Printer, Timer, Disk Controller.
* **In 8085:** The hardware interrupts are (ordered by priority):
  
  | Interrupt | Priority |
  | :---    | :---    |
  | TRAP    | Highest |
  | RST 7.5 | 2nd |
  | RST 6.5 | 3rd |
  | RST 5.5 | 4th |
  | INTR | Lowest |

### 2. Software Interrupts
* **Definition:** Intxerrupts generated by executing special instructions in a program.
* **In 8085:** Generated by instructions `RST 0` through `RST 7`.
* **Example:** `RST 1`
  * When executed, the CPU jumps to a predefined memory location.
  * Executes the interrupt service routine.
  * These interrupts are generated by software, not hardware devices.

### 3. Vectored Interrupts
* **Definition:** Interrupts whose service routine address (vector address) is already fixed/predefined. CPU automatically knows where to jump.
* **8085 Vectored Interrupts:**
  
  | Interrupt | Vector Address |
  | :--- | :--- |
  | TRAP | 0024H |
  | RST 7.5 | 003CH |
  | RST 6.5 | 0034H |
  | RST 5.5 | 002CH |

  * *Note:* Since the address is predefined, no external device needs to supply the address.
  * **Example:** When `TRAP` occurs, the CPU automatically jumps to `0024H`.

### 4. Non-Vectored Interrupts
* **Definition:** Interrupts whose service routine address is NOT predefined. The interrupting device must provide the address.
* **In 8085:** Only `INTR` is non-vectored.
* **Example:** When `INTR` occurs:
  1. CPU asks: *"Where should I go?"*
  2. External hardware provides the ISR address.
  3. CPU jumps there.

### 5. Maskable Interrupts
* **Definition:** Interrupts that can be enabled or disabled by software. The CPU can ignore them if required.
* **In 8085:** `RST 7.5`, `RST 6.5`, `RST 5.5`, and `INTR` are maskable.
* **Example:** Suppose the CPU is doing a critical task. The program executes `DI` (Disable Interrupts). Now these interrupts will not be accepted.

### 6. Non-Maskable Interrupts
* **Definition:** Interrupts that cannot be disabled. The CPU must respond immediately.
* **In 8085:** Only `TRAP` is non-maskable.
* **Example:** A power failure occurs and `TRAP` is generated. Even if interrupts are disabled via `DI`, the CPU still services the `TRAP`.

## Important 8085 Interrupts

### TRAP
* **Features:** Highest priority, Non-maskable, Vectored.
* **Used For:** Critical events (e.g., Power failure, Emergency shutdown, Serious hardware faults).

### RST 7.5
* **Features:** Maskable, Vectored, Edge-triggered.
* **Priority:** Second highest.

### RST 6.5
* **Features:** Maskable, Vectored, Level-triggered.
* **Priority:** Third highest.

### RST 5.5
* **Features:** Maskable, Vectored, Level-triggered.
* **Priority:** Fourth highest.

### INTR
* **Features:** Maskable, Non-vectored, Lowest priority.
* **Requirement:** Requires external hardware to provide the ISR address.

---

## Priority Order (Highest to Lowest)

```
  TRAP (Highest)
   ↓
  RST 7.5
   ↓
  RST 6.5
   ↓
  RST 5.5
   ↓
  INTR (Lowest)
```

### Memory Trick
* **TRAP (T):** **T**op Priority, cannot be disabled.
* **INTR (I):** **I**nterrupt Request, lowest priority, needs external ISR address.

## Exam-Oriented Summary

* **Hardware Interrupts:** Generated by external devices.
* **Software Interrupts:** Generated by instructions such as `RST 0`–`RST 7`.
* **Vectored Interrupts:** Have predefined service routine addresses.
* **Non-Vectored Interrupts:** Need external hardware to supply the address.
* **Maskable Interrupts:** Can be disabled by software.
* **Non-Maskable Interrupts:** Cannot be disabled; the CPU must service them.
* **8085 Priority Order:** `TRAP` > `RST 7.5` > `RST 6.5` > `RST 5.5` > `INTR`
