# Computer Architecture

## Definition

Computer architecture refers to the features of a computer that are visible to the programmer. It describes what the computer can do.

## Key Points

- Visible to the programmer
- Affects how programs are written and executed
- Describes the services and abstractions the computer provides

## Examples

- Instruction Set Architecture (ISA)
- Number of bits
- Memory addressing
- I/O mechanisms
- Available instructions


# Computer Organization

## Definition

Computer organization describes how the hardware is built and connected to realize the architecture. It explains how the computer performs its functions.


How the computer actually implements those features. It deals with the internal hardware.
## Key Points

- Not usually visible to the programmer
- Focuses on hardware implementation
- Describes internal workings of the computer

## Examples

- Control signals
- CPU and peripheral interfaces
- Memory technology (RAM type, cache, etc.)
- Internal hardware connections


| Computer Architecture                      | Computer Organization                                                             |
| ------------------------------------------ | --------------------------------------------------------------------------------- |
| Tells **what** the computer does.          | Tells **how** the computer does it.                                               |
| Visible to programmers.                    | Hidden from programmers.                                                          |
| Focuses on system design.                  | Focuses on hardware implementation.                                               |
| Example: Has a multiplication instruction. | Example: How multiplication is performed (special hardware or repeated addition). |
