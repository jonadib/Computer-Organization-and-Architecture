MEMORY SIZE AND ADDRESS BITS

    Total Memory: 4096 × 16
    • Total memory locations = 4096
    • Each memory word size = 16 bits
    • Since 4096 = 2¹², 12 bits are required for addressing

INSTRUCTION FORMAT (16 bits)

    ┌──────────15──┬────────────┬12──────────────┐0
    │  I Bit     │   Opcode   │   Operand    │
    │  (1 bit)   │  (3 bits)  │  (12 bits)   │
    └────────────┴────────────┴──────────────┘

    • I Bit:     Indirect addressing indicator
    • Opcode:    Specifies operation (ADD, SUB, LOAD, STORE, etc.)
    • Operand:   Contains address or data

CPU REGISTERS

1. ADDRESS REGISTER (AR)
   ─────────────────────
   Size:       12 bits
   Purpose:    Stores memory address for CPU access
   Function:   Holds memory addresses for read/write operations

   Example:    To read from location 1002 → AR = 1002


2. DATA REGISTER (DR)
   ──────────────────
   Size:       16 bits
   Purpose:    Stores data from memory or data to write
   Function:   Temporary data holder between CPU and memory

   Example:    Memory[1002] = 25 → DR = 25


3. ACCUMULATOR (AC)
   ─────────────────
   Size:       16 bits
   Purpose:    Stores arithmetic and logical results
   Function:   Primary register for ALU operations

   Example:    AC ← 5; Add 3 → AC = 8


4. PROGRAM COUNTER (PC)
   ─────────────────────
   Size:       12 bits
   Purpose:    Stores address of next instruction
   Function:   Tracks program execution sequence

   Example:    PC = 100 → after execution → PC = 101


5. INSTRUCTION REGISTER (IR)
   ─────────────────────────
   Size:       16 bits
   Purpose:    Stores current instruction being executed
   Function:   Enables instruction decoding

   Example:    IR = ADD 450


6. TEMPORARY REGISTER (TR)
   ───────────────────────
   Size:       16 bits
   Purpose:    Stores intermediate values during processing
   Function:   Temporary storage during CPU operations

   Example:    During multiplication 5×4 → TR = 20


7. INPUT REGISTER (INPR)
   ──────────────────────
   Size:       8 bits
   Purpose:    Stores input data from input devices
   Function:   Receives data from keyboard, scanner, mouse, etc.

   Example:    User presses 'A' (ASCII 65) → INPR = 65


8. OUTPUT REGISTER (OUTR)
   ───────────────────────
   Size:       8 bits
   Purpose:    Stores data for output devices
   Function:   Sends processed data to monitor, printer, etc.

   Example:    Display 'B' (ASCII 66) → OUTR = 66

OPCODE AND OPERAND

OPCODE
    • Specifies the operation to perform
    • Examples: ADD, SUB, LOAD, STORE
    • In "ADD R1, R2" → ADD is the opcode

OPERAND
    • Specifies data or address for the operation
    • In "ADD R1, R2" → R1 and R2 are operands

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
| Register | Full Name            | Function                 |
| -------- | -------------------- | ------------------------ |
| AR       | Address Register     | Holds memory address     |
| DR       | Data Register        | Holds memory data        |
| AC       | Accumulator          | Arithmetic results       |
| PC       | Program Counter      | Next instruction address |
| IR       | Instruction Register | Current instruction      |
| TR       | Temporary Register   | Temporary storage        |
| INPR     | Input Register       | Input data               |
| OUTR     | Output Register      | Output data              |

INSTRUCTION EXECUTION EXAMPLE

Instruction:    ADD 450 (stored at address 100)
Initial State:  Memory[450] = 20, AC = 5

    Step 1:  PC = 100                      (Address of instruction)
    Step 2:  AR = PC = 100                 (Transfer address)
    Step 3:  DR = Memory[100] = ADD 450    (Fetch instruction)
    Step 4:  IR = ADD 450                  (Transfer to IR)
    Step 5:  PC = 101                      (Increment PC)
    Step 6:  AR = 450                      (Decode operand address)
    Step 7:  DR = Memory[450] = 20         (Read operand)
    Step 8:  AC = AC + DR = 5 + 20 = 25   (Execute addition)

    Final Result:  AC = 25

    Suppose memory contains:

    Address	Data
     300	5
     450	20

    And program instructions are:

   Address	Instruction
     100	LOAD 300
     101	ADD 450

   Step 1: LOAD 300

   Instruction:

    LOAD 300
       means: “Take data from memory location 300 and place it into AC.”

    Since:

        Memory[300]=5
       After execution:

         AC=5
  Step 2: ADD 450

Instruction:

ADD 450
        means: “Add data from memory location 450 to AC.”

Since:
    Memory[450]=20

CPU does:
    AC=AC+Memory[450]

So:
    AC=5+20

Final:
    AC=25

Important Concept
The accumulator usually does not magically create values.

It gets values from:

    Memory
    Previous operations
    Input devices
    Other registers
